Graphify

Cursor reads files one at a time. Graphify maps your repo into a queryable knowledge graph — functions, callers, imports, SQL tables, config keys. The agent queries the graph instead of grepping. ~71× fewer tokens on relationship questions.

What it does

One command builds graphify-out/graph.json from your codebase. Ask graphify query or graphify path — answers come back as explicit graph paths with file:line citations. On-device, no API keys, Apache 2.0.

Install on Windows + Cursor (~10 min)

1

Install CLI

uv tool install graphifyy

Package is graphifyy (double-y). Command is graphify. If not found: uv tool update-shell → new terminal.

2

Hook Cursor

graphify cursor install

Creates .cursor/rules/graphify.mdc — restart Cursor.

3

Build graph (in your repo)

cd your-repo
graphify .

PowerShell: use graphify . not /graphify . (slash = path separator).

4

Test

graphify query "what calls this method?"
graphify path "A" "B"

Where it earns its keep

  • Onboarding new repos
  • Impact analysis before edits
  • Fewer wrong cross-file changes
  • Architecture / call-flow questions

Works great with RTK

RTK compresses terminal output. Graphify cuts exploration tokens. Together: longer sessions, smarter answers on big codebases.
