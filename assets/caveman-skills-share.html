Caveman skill pack

Free skills that cut AI output noise — shorter replies, commits, and reviews without losing technical accuracy. One install gives you 9 skills. Use in any Cursor chat with /command or natural language.

Install globally (once)

npx skills add JuliusBrussee/caveman -a cursor

Installs to %USERPROFILE%\.agents\skills\ — works in every project.

See what's installed

npx skills list -g

Without -g only shows skills inside the current repo folder.

How to call in Cursor chat

Type / in agent chat → pick skill, or type the command below. Start with /caveman full for shorter replies.

/caveman lite /caveman full /caveman ultra /caveman wenyan /caveman off /caveman-help

All 9 skills — purpose & how to invoke

Skill Purpose Call in chat
caveman Terse AI replies — ~65% fewer output tokens. Code quality unchanged. /caveman full (default) · lite · ultra · wenyan · off
caveman-commit Short Conventional Commit messages — subject ≤50 chars, body only when needed. /caveman-commit or "write a commit message"
caveman-review One-line PR comments: location, problem, fix. No essay feedback. /caveman-review or "review this PR"
caveman-compress Shrink CLAUDE.md / memory files to caveman prose — saves input tokens. /caveman-compress <filepath>
caveman-help Quick reference card for all modes and commands. /caveman-help
caveman-optimize Evaluate token-optimization observations (needs Caveman CLI login). Ask to inspect optimization report · advanced
investigate-first Diagnose before editing — evidence first, no shotgun fixes. Say "investigate first" on bugs / unknown failures
lean-build Keep feature scope narrow — stop when acceptance criteria met. Use when building new features — avoids over-engineering
find-skills Discover & install more skills from the ecosystem. "Find a skill for X" · npx skills find in terminal

Suggested starter combo

1. Install once globally → 2. /caveman full in every chat → 3. Add RTK + Graphify for terminal & codebase tokens → 4. Use investigate-first on bugs, lean-build on new features.
