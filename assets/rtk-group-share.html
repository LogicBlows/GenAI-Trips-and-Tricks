RTK — Rust Token Killer

Compresses terminal output before it hits Cursor's context window. Git status, tests, grep — less noise, longer sessions. You don't change how you work.

What it does

Every time Cursor runs git status, ls, grep, or a test suite, the raw output floods the context window. RTK auto-rewrites those commands and returns a compact summary — same signal, ~80% fewer tokens.

Install on Windows + Cursor (~10 min)

1

Download RTK

github.com/rtk-ai/rtk/releases → rtk-x86_64-pc-windows-msvc.zip

2

Put rtk.exe on PATH

Copy to %USERPROFILE%\.local\bin (Win+R → paste that path)

3

Hook Cursor (new PowerShell)

rtk init -g --agent cursor

Say N to Claude settings.json if you only use Cursor · N to telemetry (optional)

4

Restart Cursor

Fully close and reopen. Verify: rtk init --show
