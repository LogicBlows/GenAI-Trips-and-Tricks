RTK (Rust Token Killer)

Added this week · Token optimization

Every time Cursor runs git status, ls, grep, or a test suite, the raw terminal output goes straight into the context window. RTK compresses that output before it lands — same signal, far fewer tokens. You don't change how you work; the hook rewrites commands automatically.

What it saves

Typical compression:

Directory listing   2K → 400 tokens   (80%)
Git status          3K → 600          (80%)
Test runners       25K → 2.5K         (90%)
Whole session     ~118K → ~24K        (~80%)

Roughly 3× longer sessions before you hit a context limit — fewer "start a new chat and re-explain everything" resets.

1. Download

github.com/rtk-ai/rtk/releases → rtk-x86_64-pc-windows-msvc.zip

2. Put on PATH

Copy rtk.exe to %USERPROFILE%\.local\bin (Win+R → paste that path).

3. Hook Cursor 
rtk init -g --agent cursor
4. Verify 
rtk init --show
5. Restart Cursor

Fully close and reopen Cursor so the hook loads.

Not an error — the Claude Code prompts

When you run rtk init -g --agent cursor, RTK also configures Claude Code because -g is global. You may see:

  • A prompt to patch .claude\settings.json
  • "Restart Claude Code" in the output
  • Local (./CLAUDE.md): not found in rtk init --show

Cursor-only users: say N to the Claude settings.json prompt — Cursor is already hooked separately. The "Local CLAUDE.md not found" line is fine; it only matters if you use Claude Code in that project. What matters for Cursor is [ok] Cursor hook: registered in hooks.json.

Telemetry: RTK asks to enable anonymous aggregate usage stats (command counts, savings — not your code or file paths). It is off by default and requires explicit opt-in. For internal bank use, we recommend N. Change later with rtk telemetry disable or rtk telemetry enable.

Check your numbers

rtk gain              # summary
rtk gain --graph      # 30-day chart
rtk gain --history    # recent commands

Optional: install ripgrep (winget install BurntSushi.ripgrep.MSVC) so grep-style filters work without warnings.
