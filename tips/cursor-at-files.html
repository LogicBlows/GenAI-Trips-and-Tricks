Point Cursor at the right files

8 Oct 2026 · Cursor · Productivity

Cursor works best when it reads the files you care about. Use @ in chat to attach a file, folder, or symbol instead of describing paths from memory.

Example prompt

Vague:

Fix the ChatGPT install guide images.

Better:

@tools/chatgpt.html — Step 1 caption should match the new Go screenshot in @assets/chatgpt/01-plugins-page.png
1. Attach context

Type @ and pick files or folders relevant to the task.

2. State the outcome

One sentence on what should change and what should stay the same.

3. Add constraints if needed

e.g. “match existing CSS”, “no new dependencies”, “don’t commit”.
