One ChatGPT project per plugin

8 Oct 2026 · ChatGPT · Setup

On ChatGPT Go and Free, there is no Skills tab — only Plugins (connectors) and Projects. Treat each internal plugin as its own Project so instructions do not mix.

1. Name the project after the plugin

e.g. OCR Document Processor — not “AI stuff”.

2. Paste instructions once

⋯ → Project settings → paste the block from the plugin page → Save.

3. Chat in the Chats tab

Sources is optional (Drive/Slack). Day-to-day use is Chats → new chat inside that project.

Go & Free: Upload limits apply. Outputs are drafts — verify before official or client use.
